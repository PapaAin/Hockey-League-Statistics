# NHL Hockey League Statistics Application

## Description
This project involves developing an interactive application that allows users to explore NHL hockey league statistics from the 2019-20 season using various analytical functions. 
The application will prompt users to specify a JSON data file—either partial.json (a smaller dataset for testing) or all.json (a comprehensive dataset with all NHL player stats from the season).

## Core Features:
-	Search for a specific player's statistics by name.

-	Display all NHL team abbreviations in alphabetical order.

-	Display all country abbreviations in alphabetical order.

## Advanced Features:
-	List all players from a specific team, ranked by total points (Goals + Assists) from highest to lowest.

-	List all players from a specific country, ranked by total points from highest to lowest.

## Expert Features:
-	Display the top n players who have scored the most points, prioritizing players with more goals in case of ties.

-	Display the top n players who have scored the most goals, prioritizing players who have played fewer games in case of ties.
